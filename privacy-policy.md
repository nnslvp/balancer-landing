## Сбор и использование данных

Приложение Balancer использует Firebase для обеспечения функциональности приложения. Мы собираем и обрабатываем только те данные, которые необходимы для работы приложения.

## Какие данные собираются

### Данные приложения

- Данные о группах и участниках
- История транзакций и расходов
- Настройки приложения

### Технические данные

Через Firebase могут собираться следующие технические данные:

- Информация об устройстве (модель, версия операционной системы)
- Данные о взаимодействии с приложением
- Информация о сбоях и ошибках приложения

## Использование Firebase

Приложение использует следующие сервисы Firebase:

- **Firebase Authentication** — для аутентификации пользователей
- **Firebase Firestore/Realtime Database** — для хранения и синхронизации данных между устройствами
- **Firebase Analytics** — для анализа использования приложения и улучшения пользовательского опыта
- **Firebase Crashlytics** — для мониторинга стабильности приложения

## Безопасность данных

Все данные передаются по защищенному соединению (HTTPS/TLS) и хранятся на серверах Firebase с соблюдением стандартов безопасности Google.

## Передача данных третьим лицам

Мы не продаем и не передаем ваши личные данные третьим лицам. Данные обрабатываются исключительно сервисами Firebase (Google) в соответствии с их [политикой конфиденциальности](https://policies.google.com/privacy).

## Изменения в политике конфиденциальности

Любые изменения в политике конфиденциальности будут опубликованы на этой странице и вступят в силу с выходом следующей версии приложения.
