# Balancer Landing Page

Лендинг для приложения Balancer — умного трекера совместных расходов с автоматической минимизацией переводов.

## Технологии

- Jekyll 3.9.5
- GitHub Pages
- Минимальный и современный дизайн
- SEO-оптимизация

## Локальная разработка

```bash
bundle install
bundle exec jekyll serve
```

Сайт будет доступен по адресу http://127.0.0.1:4000/

## SEO

Сайт оптимизирован для поисковых систем:
- Семантическая HTML-разметка
- Open Graph и Twitter Card метатеги
- Структурированные данные (JSON-LD)
- robots.txt и sitemap.xml
- Оптимизированные заголовки и описания страниц

## Структура

- `index.md` — главная страница
- `contacts.md` — контакты
- `privacy-policy.md` — политика конфиденциальности
- `assets/main.scss` — стили сайта
- `_config.yml` — конфигурация Jekyll
