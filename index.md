# Balancer

Кроссплатформенное приложение для учета совместных расходов с автоматической минимизацией переводов.

- Отслеживание трат в группах и по участникам
- Гибкое разделение по коэффициентам (1, 2, 0.5 и т.д.)
- Автоматический пересчет долгов и сокращение количества переводов
- Мультивалютность с фиксированным курсом на момент операции
